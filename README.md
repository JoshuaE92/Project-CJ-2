# Operation CJ-2 ✈️

“Once you have tasted flight, you will forever walk the earth with your eyes turned skyward." – Leonardo da Vinci

## 🚀 Project Overview
Operation CJ-2 is a beginner-friendly project to design, build, and fly a fully functional RC (Remote-Controlled) airplane — with both manual and autonomous flight modes.

This repo will contain the **software side** of the plane, developed by the CS lead (me 😎). It will focus on:
- RC signal interpretation
- Stabilization algorithms (PID control)
- Autonomous flight logic
- Communication with Arduino/hardware

## 🛠️ Project Goals
- Build a working RC airplane with a single propeller
- Develop a basic autonomous flight mode
- Integrate camera (TBD after prototype)
- Stay within $200–$300 budget
